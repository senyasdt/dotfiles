# LeopardWM: основной менеджер master

Официальный portable LeopardWM 0.3.4, без изменений его исходников. Имя каталога
`leopardwm-test` сохранено для совместимости существующих путей. Настройки новой
машины задаёт `.chezmoidata/windows-desktop.json` и развёрнутый `desktop.json`.
`settings.json` читается только как совместимость старого WorkingFolder-профиля.

## Установка и выбор

[Общий Windows restore](../../../provision/windows/README.md) в master теперь
включает установку и активацию LeopardWM. Отдельные дополнительные шаги после
restore не нужны. Для ручной установки существующего YASB-профиля:

```powershell
.\Install-LeopardWM.ps1
.\LeopardWM.cmd
# Запасной менеджер:
.\Komorebi.cmd
```

Установщик проверяет SHA256 официального zip и манифест уже установленного
релиза. Бинарники, состояние, дампы, снимки и release.json находятся в private
runtime и исключены из Git/chezmoi. PATH, службы и второй Startup не добавляются.
Существующий Start-DesktopWM запускает выбранный WM. На HOMEPC его вызывает
ранняя задача Desktop Session; прежний Startup komorebi.cmd сохранён в backup.

В ↻ одна группа текущего WM: запуск, остановка, перезапуск, переход к другому
менеджеру; для LeopardWM также обзор. Если панель недоступна, открыть cmd-файлы
этого каталога. Аварийный выход LeopardWM: Win+Ctrl+Esc, затем Komorebi.cmd.
Явный локальный выбор в runtime/selection.json важнее default; повреждённый
выбор останавливает запуск, а не включает другой менеджер.

## Поведение

| Действие | Сочетание |
| --- | --- |
| Следующее/предыдущее окно | Alt+колесо, Alt+H/L |
| Пространство | Alt+1…9 |
| Перенести окно | Alt+Shift+1…9 |
| Перемещение внутри колонки | Alt+J/K |
| Изменить порядок колонок | Alt+Shift+H/L |
| Следующая/предыдущая ширина | Alt+= / Alt+- |
| Плавающее окно | Alt+T |
| Полный экран | Alt+Shift+F |
| Максимальная колонка / центрирование | Ctrl+Alt+M / Ctrl+Alt+C |
| Обзор | Ctrl+Alt+Space |
| Объединить соседнее окно в колонку | Ctrl+Alt+, / Ctrl+Alt+. |
| Вкладки / пауза | Ctrl+Alt+T / Ctrl+Alt+P |

F-клавиши сохранены. Все 9 пространств — лента, боковые поля 8 px, без
искусственного peek; штатные ghost-анимации 200 ms/EaseOut. Это отдельная
сессия WM: она не конвертирует сохранённые рабочие пространства komorebi.

[Стартовые размеры](APP-WIDTH-PROPOSAL.md): Telegram 50%, редакторы/CAD/слайсеры
100%, базовый размер 61.8%; пресеты 38.2/50/61.8/80/100%. 100% — ширина рабочей
области, не fullscreen. Unity/Hub — пространство 8, Fusion/Orca/Prusa — 9.
Правила применяются к новым окнам и не затирают текущую ручную ширину.

Для плавающих окон в `[behavior]` включено `floating_above_tiled = true`:
штатный режим предназначен для поднятия окон над лентой текущего пространства.
Штатное отслеживание фокуса должно оставаться
включённым (`track_focus_changes`, по умолчанию true). Это не системный режим
«поверх всего»: полноэкранные приложения, обзор и пауза WM исключены.
Для возврата обычного перекрытия поставить `floating_above_tiled = false`
и перечитать конфигурацию без перезапуска приложений.

Проверка HOMEPC 2026-10-29: этот режим **не устранил перекрытие AmneziaVPN**
при смене фокуса, включая после чистого запуска WM и без ghost-анимации.
Обычный Win32 `HWND_TOP` возвращает успех, но измеренный порядок окон не
меняется; синхронизация ввода и `SWP_NOSENDCHANGING` результата не дали.
Краткое закрепление `HWND_TOPMOST` подтвердило поднятие без смены фокуса;
после проверки оно снято. Доступный ручной обход через уже работающий PowerToys
Always On Top: активировать Amnezia и нажать Win+Ctrl+T; повторное нажатие
снимает закрепление. Это отдельный режим поверх окон, а не подтверждение
работоспособности `floating_above_tiled`.

Для автоматического варианта теперь используется встроенный в DesktopBridge
[guard всплывающих окон](../yasb-catppuccin/README.md#верхняя-панель-и-меню).
Начальный список — AmneziaVPN; собственное закрепление снимается при запуске
игр из существующих правил ScriptLauncher и при активном fullscreen. В ↻ есть
переключатель и открытие списка. LeopardWM остаётся официальным и непатченым.

## Интеграция и возврат

YASB показывает `LWM · N`: ЛКМ — обзор, ПКМ — обслуживание. Один краткий запрос
раз в 2 s получает ограниченный по времени snapshot. Подписка komorebi и его
hook Alt+колеса в этом режиме отключены. Док использует видимые окна; только
Qt popup у самого дока удерживает его открытым. Нативные диалоги и верхний трей
не фиксируют нижнюю панель.

Переключатель сохраняет исходную панель, конфиг и при наличии состояние komorebi;
закрывает прежний WM до запуска второго. Для старых ширин проверяет тот же
порядок HWND. Restore новой сборки после возврата делает Refresh современной
панели. Архивный снимок не изменяется. Неизвестные владельцы процессов не закрываются.
LeopardWM запускается без отдельного watchdog. AHK и HID управляются самостоятельно.

После сбоя входа 28 октября запуск проверяет через IPC не только status, но и
эффективные сочетания из сохранённого TOML. При стандартных Ctrl+Alt вместо Alt
сначала выполняется reload, затем при необходимости один перезапуск проверенного
владельца. Профильные пути нормализуются; бесконечного цикла перезапусков нет.
Диагностика несовпадения — `runtime/startup.log`, общий вход —
`../runtime/session-startup.log`. Штатный бинарник LeopardWM не изменён.

Refresh сохраняет LWM-адаптер. Build обновляет staged controller и его hash, чтобы
следующий переход не возвращал старое меню. `-Operation Reload` сохраняет прежний
TOML, применяет source без рестарта WM и возвращает конфиг при ошибке reload.

Проверены runtime HOMEPC, возврат к komorebi, сохранение widths/порядка, native
SHA256, `lwm doctor`, изолированная установка и повторный запуск installer,
resolver/first-login/PS5.1/PS7. Текущий wrapper поддерживает один монитор.
Полный clean-VM restore и reboot не проверены. Проверки с повышенными окнами
ограничены правами обычного пользователя; весь WM не повышается автоматически.
