# Cold Grey: единая палитра приложений

Основа — согласованный с владельцем серый YASB, без возвращения зелёного фона.
`palette.json` задаёт графит, светлый текст и приглушённые голубые акценты.
Зелёный/красный/жёлтый сохраняют значение в коде и статусах.

| Роль | Цвет |
| --- | --- |
| Основной фон | `#202227` |
| Рамка/боковые панели | `#1c1e22` |
| Поля и карточки | `#343840` |
| Разделители | `#4b515c` |
| Текст | `#d6d9df` |
| Вторичный текст | `#9aa3b1` |
| Акцент | `#8eaee8` |
| Приглушённый акцент | `#acb9ca` |

Интерфейс — системный Segoe UI, код/терминалы — установленный
JetBrainsMono Nerd Font Mono. Размеры зависят от приложения. Прозрачность
остаётся функцией конкретного приложения: Windows Terminal/WezTerm
поддерживают собственные backdrop/opacity. Chrome настраивается штатными средствами.

## Где используется

- YASB уже использует исходную серую палитру; его CSS и процессы здесь не меняются.
- VS Code: встроенная Default Dark Modern с scoped color/token overrides.
  Расширение не требуется; при выборе другой темы эти overrides не действуют.
- Windows Terminal: схема Cold Grey, dark UI, единые defaults для профилей.
  Имена профилей, команды, клавиши и фоновые изображения сохраняются.
- WezTerm: сохранён Nord Cold Grey, opacity 0.60, фон solid, Windows font size 10.
  Значения задаёт `.chezmoidata/windows-desktop.json`, TOML темы хранится в source.
  Обычный Apply заполняет отсутствующее состояние и сохраняет существующий выбор.
  Явный RestoreWezTerm возвращает сохранённые тему, opacity и фон; клавиши не меняет.
- Neovim full: Cold Grey добавлен в существующий theme_sync поверх Catppuccin.
  Генератор не устанавливает плагины и не подменяет engine/интеграции.
- Chrome: стандартное оформление по выбору владельца; исключён из наших адаптеров.
- Obsidian: необязательный `obsidian/cold-grey.css`. Применяется вручную к
  выбранному vault; скрипт не ищет заметки и не устанавливает плагины.

Генерация из source: `python3 provision/windows/generate_appearance.py`.
Проверка без записи: та же команда с `--check`. Генерируются native adapters,
Code/Terminal source settings и Neovim palette. Геометрия YASB редактируется
отдельно. Изменения его основных цветов следует согласовывать с palette.json.

## Применение и возврат на Windows

После точечного chezmoi apply файлов оформления:

```powershell
.\Manage-Appearance.ps1 -Action Status
.\Manage-Appearance.ps1 -Action Apply -WhatIf
.\Manage-Appearance.ps1 -Action Apply
```

На текущем HOMEPC папка — `WorkingFolder/desktop-customization/appearance`;
на новом ПК — `.config/desktop-customization/appearance`.
`restore.ps1 -Profiles full,desktop -Bar yasb -Theme catppuccin -Apply` вызывает
этот помощник после установки профиля. Сам помощник не обновляет программы,
не меняет автозапуск, AHK, komorebi, Chrome Preferences или состояние YASB.
Нет постоянного нового процесса.

Команда объединяет только поля оформления с существующими Code/Terminal JSON.
Неподдерживаемый JSONC вызывает отказ до записи. WezTerm получает адаптер Cold Grey;
его текущие theme/active_scheme.toml, opacity и background_mode сохраняются.
Если state отсутствует, используется сохранённый Nord Cold Grey / 0.60 / solid.
Все меняемые файлы сначала сохраняются побайтово в `backup/<date-id>`
с SHA256 и манифестом. Для возврата:

```powershell
.\Manage-Appearance.ps1 -Action Restore -Backup '<полный путь из результата Apply>' -WhatIf
.\Manage-Appearance.ps1 -Action Restore -Backup '<полный путь из результата Apply>'
```

Если после применения файл менялся, Restore останавливается и просит сравнить
его с копией. Не подменять свежие пользовательские настройки старым файлом.
При неполной записи исходные `.old` и манифест остаются для ручного восстановления.
`-TargetHome` предназначен для проверки отдельного/офлайн профиля; по умолчанию
используются текущий UserProfile и стандартные APPDATA/LOCALAPPDATA.

## Вернуть сохранённый WezTerm

После применения chezmoi файлов WezTerm и appearance:

```powershell
.\Manage-Appearance.ps1 -Action RestoreWezTerm -WhatIf
.\Manage-Appearance.ps1 -Action RestoreWezTerm
```

Возвращает четыре state-файла; Code/Terminal не читаются и не меняются.
Копия и guarded Restore работают так же, как выше. Отсутствующий TOML темы
вызывает отказ до записи. Шрифт 10 задаёт сам Windows-конфиг chezmoi.
Обновление source не делает Git-снимок новых пользовательских предпочтений:
для следующего восстановления их нужно осознанно сохранить в shared defaults.

## Chrome

27 октября 2026 владелец выбрал стандартное оформление Chrome и отказался
от наших экспериментов. Самодельные тема и новая вкладка удалены из текущих
dotfiles, генератора и рабочей папки. Restore не устанавливает их повторно.
Браузер, его текущие настройки, закладки и расширения этим помощником не меняются.

| Discord | Установлен и работает в фоне. Стандартная Dark близка к графиту; custom theme потребует отдельной поддержки/модификации. Ничего в клиент не внедрено |
| Telegram | Установлен; поддерживает native themes. Текущая палитра из бинарных данных не извлекалась; настройку делать через Appearance после выбора пользователем |
| Obsidian | Установлен, vault в стандартном реестре не обнаружен. Snippet подготовлен, к заметкам не применён |
| Unity / Blender | Установлены; штатные dark themes. Кастомную тему редактора проверять отдельно; проекты, сцены, ассеты и keymaps не менялись |
| Steam | Установлен. Базовый dark согласуется по тону; полная замена требует отдельного skin/mod. Изменения не выполнялись |
| Vial / HID | Редактор ради темы не открывался. Настройку Qt делать отдельно от прошивки, раскладки и работающих HID helpers |
| ChatGPT | Индивидуальная палитра в этом аудите не менялась. Не внедрять CSS/патчи ради совпадения фона; прежнее восстановление отрисовки остаётся отдельной командой |

Установленность и прочитанный конфиг не равны визуальной проверке окна.
Discord, Telegram, Unity/Blender и новый GUI вид Code/Terminal не были
подтверждены владельцем. Реальные игры, античит, reboot и чистая VM не проверялись.

WSL имеет отдельную домашнюю директорию. Windows-помощник её не изменяет.
Историческая операция с WSL state сохранена в точной архивной версии этого
документа; она не является инструкцией восстановления нового Windows-профиля.
