# Cold Grey — New Tab

Адаптивная новая вкладка Chrome в общей палитре Cold Grey.

## Установка

1. Оставить тему **Cold Grey** включённой: она задаёт цвета вкладок и адресной строки.
2. Открыть `chrome://extensions`, включить «Режим разработчика».
3. «Загрузить распакованное расширение» → выбрать папку **chrome-newtab**,
   не соседнюю **chrome** (это тема).
4. Открыть новую вкладку. Если Chrome спросит о смене новой вкладки,
   подтвердить сохранение выбранного расширения.

HOMEPC: `C:\Users\druzh\WorkingFolder\desktop-customization\appearance\chrome-newtab`.
После восстановления dotfiles на новой Windows: `%USERPROFILE%\.config\desktop-customization\appearance\chrome-newtab`.
Установка расширения остаётся разовым действием в браузере; restore не меняет
Chrome Preferences, политики, профиль или список установленных расширений.

Тема и расширение работают вместе. Отдельно загружать картинку через
«Настроить Chrome» не нужно. Для возврата штатной новой вкладки выключить
**Cold Grey — New Tab** в `chrome://extensions`; тема останется включена.
Перед удалением расширения сделать экспорт ярлыков: при удалении Chrome
стирает его локальное хранилище.

## Как пользоваться

- Поиск отправляет введённый запрос в Google только после Enter или нажатия стрелки.
- «Настроить» открывает список ярлыков. Название строки — редактирование,
  стрелки — порядок, × — удаление. Можно добавить до 24 ярлыков.
- Поддерживаются адреса http/https; системные команды и javascript URL запрещены.
- Esc, крестик и клик за пределами меню закрывают его.
- «Экспорт» сохраняет `cold-grey-shortcuts.json`; на новом ПК установить
  расширение и выбрать этот файл через «Импорт», затем подтвердить замену списка.
- Личные ярлыки хранятся только в `chrome.storage.local`; не попадают в dotfiles
  или Google Sync автоматически. Не коммитить личный экспорт по умолчанию.
- `defaults.json` задаёт стартовый список только пока нет сохранённого списка.
  Пустой пользовательский список остаётся пустым. Обновление расширения
  не перезаписывает пользовательские ярлыки.

## Оформление

На широком окне панель слева, рисунок справа. При ширине до 700 CSS px рисунок
располагается над панелью. `object-fit: contain` всегда показывает весь рисунок,
сохраняет пропорции и оставляет графитовые поля при несовпадении размеров.
На очень низком/узком окне доступна обычная вертикальная прокрутка.

Палитра `palette.css` и PNG генерируются из общего `appearance/palette.json`
и одобренной картинки `appearance/chrome/images/maomao-cold-grey-dark.png`:

```sh
python3 provision/windows/generate_appearance.py
python3 provision/windows/generate_appearance.py --check
```

Картинка: Maomao, Nyte_Tyde; только обычная цветокоррекция оригинала, без
ИИ-перерисовки. Подробности и SHA256 в `WALLPAPER.md`.

## Устройство и проверка

Manifest V3, `chrome_url_overrides.newtab`, только разрешение `storage`.
Нет service worker, content scripts, доступа к истории/закладкам/вкладкам,
внешних шрифтов, favicon-запросов, аналитики или сетевой загрузки при открытии.
Значки — локальные буквенные обозначения. Страница не воспроизводит
персонализированные сервисы штатной Google New Tab.

Публичный `key` манифеста обеспечивает постоянный ID расширения при переносе
папки. Это публичный ключ идентификации, не секрет; приватный ключ не хранится.
Для обновления файлов нажать «Обновить/Перезагрузить» у расширения и открыть
новую вкладку. Идентификатор и локальные ярлыки сохраняются.

Проверки разработки (Node + Playwright; только отдельный тестовый профиль):

```sh
node provision/windows/tests/chrome-newtab.test.cjs dot_config/desktop-customization/appearance/chrome-newtab /tmp/cold-grey-tests
```

`TEST_CHROME` может указывать исполняемый браузер. Проверки страницы используют
адаптер chrome.storage, а не профиль владельца. Проверены пять размеров окна,
add/edit/delete/reorder, экспорт/импорт/отмена, сохранение после reload, обработка
ошибки записи, небезопасных URL, поиск, отсутствие фоновых сетевых запросов.
27 октября 2026 реальная загрузка unpacked-расширения в headless installed Chrome
заблокирована (ERR_BLOCKED_BY_CLIENT). Ручная установка и фактический native
chrome.storage в профиле владельца ещё требуют подтверждения.

Документация: https://developer.chrome.com/docs/extensions/develop/ui/override-chrome-pages
и https://developer.chrome.com/docs/extensions/reference/api/storage .
