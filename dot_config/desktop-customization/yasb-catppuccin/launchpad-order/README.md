# Ручной порядок и поиск Launchpad

Патч для проверенной Windows-сборки YASB 2.0.7. Папки и отдельные приложения
имеют общий ручной порядок. Перетаскивание на левую/правую половину значка
вставляет перед/после него; линия показывает место вставки. Работают также
промежутки и свободная область после последнего ряда. Пустых ячеек нет.

Внутри папок порядок тоже ручной. Обычный клик запускает приложение/открывает
папку; завершение перетаскивания ничего не запускает. Состав папок меняется
через штатное меню редактирования, а не наведением на папку при сортировке.
При активном поиске перетаскивание отключено, чтобы скрытые элементы не
переставлялись неожиданно.

С версии расширения 2 при каждом открытии библиотеки фокус сразу в строке
поиска: название приложения можно печатать без дополнительного клика.
Используется тот же отложенный callback показа, который в YASB 2.0.7 выбирал
первый значок; дополнительные таймеры и постоянный перехват фокуса не нужны.
Стрелки и Tab по-прежнему позволяют перейти к значкам. Скрытая или закрывающаяся
библиотека фокус не перетягивает. Каталог, состав папок и настройки AHK не меняются.

С версии 3 обычный печатный ввод после выбора значка/клика по фону возвращается
в поиск, сохраняя первую букву и текущий запрос. Внутри папки ввод открывает
общий поиск. Shift и кириллица поддерживаются; сочетания Ctrl/Alt/Win, стрелки,
поля ввода диалогов и контекстные меню не перенаправляются. Это обработка событий
только самой открытой библиотеки, без глобального перехвата клавиатуры.

С версии 4 Backspace со значка/фона тоже возвращает фокус в поиск и выполняет
обычное удаление в строке (один символ перед курсором либо выделенный текст).
При пустом запросе он только возвращает фокус. В поле самого поиска и в диалогах
редактирования остаётся штатное поведение; Ctrl/Alt/Win-сочетания не перехватываются.

## Сохранение и восстановление

Порядок автоматически сохраняется в `~/.config/yasb/launchpad/apps.json` после
каждого переноса. Положение папки определяется первым её элементом в общем
списке; перенос папки переносит весь блок, сохраняя порядок её содержимого.
Начальный вид следует порядку записей каталога; принудительное размещение
папок по алфавиту перед всеми приложениями больше не применяется.

Схема каталога не меняется. `../Launchpad-Layout.ps1 -Action Export` сохраняет
этот же порядок в переносимом `launchpad-layout.json`. Как прежде, обновлённый
экспорт нужно перенести в source chezmoi и закоммитить. Автосохранение в
библиотеке не делает автоматический Git commit/push. При восстановлении с
патчем `Manage.ps1 -Action Apply`/`ImportApps` применяет сохранённый порядок.
Новые неизвестные приложения по-прежнему остаются вне папок.

## Установка на новой машине

1. Восстановить профиль dotfiles и установить YASB **2.0.7**, Python **3.14**.
2. Закрыть YASB. В PowerShell администратора выполнить из этой папки:
   `./Install-LaunchpadOrder.ps1 -Action Apply`.
   При нестандартном расположении Python передать `-PythonPath C:\...\python.exe`.
3. Запустить панель обычным способом через `../Start-Yasb.ps1` от обычного пользователя.

Установщик не меняет процессы, конфиг, CSS, AHK или оконный менеджер.
Проверяет версию Python и SHA-256 исходного модуля Launchpad. В `library.zip`
добавляет расширение и обёртку только этого модуля. Остальные записи архива
проверяются побайтово. Исходный модуль хранится в том же архиве для отката.
Фонового процесса нет; дополнительный Python нужен только для установки.

Проверка: `./Install-LaunchpadOrder.ps1 -Action Status`.
Откат: закрыть YASB, выполнить `./Install-LaunchpadOrder.ps1 -Action Undo`
из PowerShell администратора, затем запустить панель обычным способом.
Каталог и пользовательские папки при откате не изменяются; штатный YASB
снова отображает папки перед приложениями.

Обновление YASB может заменить архив и убрать патч. На другой сборке установщик
откажется применять несовместимый код; сначала нужна проверка/адаптация.
Не запускать панель от администратора ради этого патча.

`Start-Yasb.ps1` учитывает сохранённый выбор оконного менеджера в соседнем
`leopardwm-test/runtime/selection.json`. При LeopardWM он не требует komorebic
и его IPC; при komorebi прежняя проверка остаётся. `-CheckOnly` не запускает панель.
Проверка выбора выполняется `../Test-YasbLaunchContext.ps1 -TestRoot <временная папка>`
с подставными проверками процессов; реальные программы в этих шести случаях не запускаются.

## Проверки

Из каталога профиля создать `.tmp`, затем запустить Python 3.14:
`python -X utf8 launchpad-order/test_launchpad_order.py --qt`.
Тесты используют отдельные временные каталоги и Qt offscreen: перемещение
папок и приложений, начало/конец списка, внутренний порядок, повторное открытие,
обычный клик и отсутствие запуска при drag, поиск, изменения каталога другим
процессом. Дополнительно проверяются начальный фокус, ввод текста в фактический
focus widget, фильтрация, стрелки, повторное открытие, пустые результаты и
отсутствие перехвата фокуса скрытым popup. Проверяются собранный архив и откат патча.
Также проверяются возврат в поиск со значка, сохранение запроса/первой буквы,
Unicode, выход из папки при вводе и сохранение ввода в отдельном диалоге.
Backspace проверяется со значка, с пустым запросом, в самом поле и в диалоге;
проверяется отсутствие двойного удаления, перехвата Ctrl+Backspace и правок каталога.

Enter в строке поиска запускает первое отображаемое совпадение штатным способом
и закрывает библиотеку. Работает и Enter цифрового блока. Пустой запрос, отсутствие
результатов, удержание Enter и сочетания с Ctrl/Alt/Win не запускают приложение
через этот обработчик. После выбора значка стрелками Enter запускает выбранный
значок по прежним правилам. Ввод в других диалогах не перехватывается.
Эти случаи проверяются событиями настоящего QLineEdit; запуск приложений в тесте
заменён записью вызова, каталог и пользовательские папки остаются неизменными.

Перед атомарным сохранением порядка проверяется, что каталог не изменился.
Последнее состояние сохраняется рядом как `apps.before-manual-order.json`;
это приватный runtime-файл, его не нужно добавлять в Git.
