# YASB: Cold Grey

Текущая схема master: **LeopardWM + YASB + DesktopBridge + ScriptLauncher**.
Ветка `komorebi` использует тот же стиль и помощники с komorebi/whkd.
Нужен YASB 2.0.7 или новее; схема проверена для 2.0.7. Историческое название
каталога и theme `catppuccin` сохраняется для совместимости.

## Внешний вид и библиотека

Холодная полупрозрачная серая панель, приглушённые голубые акценты, матовый трей.
Нижний док содержит библиотеку и пользовательские running/pinned приложения.
Подложка только у активного; нет фиксированных Explorer/Terminal pins, пустого
Grouper или искусственной минимальной ширины. DesktopBridge отвечает за плавное
появление у нижнего края, автоскрытие на занятом столе и видимость на пустом.
Fullscreen имеет приоритет. Превью рядом с доком удерживает его открытым;
верхние карточки и native property sheets — нет.

Launchpad импортирует Start Menu/AppsFolder и существующие значки. Открывается
мышью или Alt+F12 без AHK; одиночный Win — управляемый AHK helper, Win+E сохраняется.
Начальные папки задаются переносимой раскладкой, существующий apps.json сохраняется.
Настройка групп в библиотеке — Edit/Group/Add to Group; перетаскивание меняет
порядок. Исправлены одинаковые размеры ячеек приложения/группы, чтобы длинное
первое название не превращало сетку в пустую. Резервная библиотека Windows:
All Applications / shell:AppsFolder, независимо от панели.

## Верхняя панель и меню

Небольшие окна из `floating-popups.json` автоматически закрепляет существующий
DesktopBridge. Начальный список — AmneziaVPN; точные имена exe и необязательный
regex класса позволяют добавлять другие утилиты. Окна не перемещаются, не
растягиваются и не получают фокус. Скрытые, свёрнутые, DWM-cloaked и практически
вынесенные за экран окна пропускаются; исходное ручное закрепление сохраняется.

Любая запущенная программа из `script-launcher/config.json` → `groups` →
`closeWhileRunning` снимает автоматические закрепления, даже после Alt+Tab из
игры. Дополнительные игры можно указать в `suspendWhileRunning`. Полноэкранное
активное окно также отключает поднятие. Неизвестные игры в оконном режиме нужно
добавить в список. Это WinEvent-наблюдение вне процессов приложений и секундная
проверка; нет новых резидентных процессов, AHK или изменений бинарника WM.

Быстрое выключение: **↻ → LeopardWM/Komorebi → Всплывающие окна поверх ленты**.
Рядом открывается файл настроек; изменения подхватываются без рестарта панели.
При неверном конфиге закрепления снимаются и остаются отключёнными до успешного
чтения. При остановке helper снимает только своё закрепление; после аварийного
выхода оставшиеся собственные метки восстанавливаются при следующем запуске.
Диагностика: `runtime/floating-popups-status.json`. Вызовы изменения слоя
асинхронны: при зависшем окне снятие может задержаться до обработки его очереди;
не следует считать это гарантией отсутствия единственного кадра при любой гонке.

HOMEPC 2026-10-29: проверены реальное автоматическое закрепление Amnezia,
снятие через игровой список (контрольная запись DesktopBridge.exe без запуска
игры), ручное выключение, некорректный конфиг, повторное включение и чистая
остановка/перезапуск helper. Проверены собственная метка, флаг TOPMOST и
неизменность геометрии. Реальный старт игры и аварийное завершение helper в
этой проверке не выполнялись. Внутренние правила учёта собственных закреплений
дополнительно проверяет `DesktopBridge.exe --test-floating`.

- `LWM · N`: пространство LeopardWM; ЛКМ — обзор, ПКМ — обслуживание.
  В режиме Komorebi возвращаются его workspaces/layout widgets.
- AHK ON/OFF: ЛКМ — всё/ничего, ПКМ — выключить всё. Команда обрабатывается
  атомарно существующим guard. ON означает разрешение запуска; игры и задержка
  после них остаются приоритетными. Счётчиков и поимённого списка в виджете нет.
- ↻: общий перезапуск или ПКМ для управления WM, AHK и Vial/ZMK. Отдельные
  скрипты, исключения и отладка доступны в ↻ → AHK. Restart не меняет ручные запреты.
- ↻ → Восстановить отрисовку ChatGPT: проверяет Store-установку, PID/родителя/путь
  и пересоздаёт только GPU subprocess. Основной процесс и чат сохраняются.
  Без совпадения проверок ничего не закрывает. Отключение GPU не применяется.
- `…`: только библиотека Windows и настройки Windows. Старые эксперименты с
  лентой/GPU/MyDockFinder и возвраты исторических тем убраны из обычного меню.
- Vial/ZMK показывают выбранные клавиатуры и вызывают существующие helpers;
  Vial открывается безопасно с приостановкой HID-помощника на время редактора.
- VPN, язык, бесплатная погода, медиа, громкость и трей сохранены. Секреты и
  пользовательские устройства восстанавливаются отдельно.

## Установка и обслуживание

[Windows restore](../../../provision/windows/README.md) — основной вход.
На существующей установке source сначала сверяется с live, затем применяются
только нужные файлы. Не запускать глобальный chezmoi apply поверх другого корня
помощников HOMEPC. Source и работающие WorkingFolder-копии могут иметь разные пути.

Manage.ps1: Build собирает controller и проверяет policy; Refresh обновляет
активный профиль, сохраняя LWM-адаптер; Start идемпотентно включает панель/bridge.
Start-Yasb нормализует IPC-пути и проверяет права до остановки работающей панели.
Все варианты ActiveLayout включают Scrolling, чтобы не попадать в цикл 2.0.7.
Start запускает DesktopBridge независимо от результата IPC-проверки YASB:
ошибка одного компонента не оставляет уже работающий док без автоскрытия.
Desktop Session повторяет неудачный запуск компонента до трёх раз с паузой 2 s
и пишет `../runtime/session-startup.log`. Это короткий запускатор, без нового
фонового процесса. При `enableAhkOnLogin` вызывает AHK Login: ON для всех при новом
входе Windows, с сохранением OFF при повторном запуске в той же сессии. Без этой
настройки вызывает Start и сохраняет ручные состояния между входами. Игровые
правила действуют в обоих вариантах. Legacy `YASB Catppuccin.lnk` не должен дублировать Desktop Session.
На HOMEPC после аудита Desktop Session — ранняя задача Планировщика с задержкой
1 s от входа; отдельная штатная задача YASB отключена. Apply распознаёт эту
задачу и не создаёт второй Startup-ярлык. [Порядок входа и откат](../../../provision/windows/STARTUP-AUDIT-2026-10-28.md).
Обычный restart WM переподключает его виджеты. Изменение config.yaml заставляет
сам YASB перезапустить панель; это не palette-only watcher. Поэтому для одной
палитры используется stylesheet watcher, без пересоздания app bars.

Исторические Restore Previous / Restore Before MyDock и snapshots сохранены
вне обычного меню. Перед полным возвратом старой темы сначала перейти на komorebi.
Снимки, runtime, apps.json, pins, иконки, логи, exe и DPAPI-данные приватные.
Не копировать их в Git и не переимпортировать библиотеку ради исправления вида.

## Проверено и ограничения

PS5.1/PS7: сборки helper, 48 AHK assertions (включая быстрый global toggle,
игру и задержку возобновления), 23 проверки appearance/rollback. Девять OS/profile
renders, три YAML по схеме 2.0.7, LWM adapter и popup policy. На HOMEPC владелец
проверил размеры и hit targets дока, скрытие, меню и скроллинг LeopardWM.
Чистая VM/reboot, реальное открытие игр и физические HID в релизном прогоне не
тестировались. Причина редкого дефекта отрисовки ChatGPT не установлена.

Предыдущая подробная история диагностики сохранена в
[Git](https://github.com/senyasdt/dotfiles/blob/1338c468883bd0763de153cf69e2087828edfe45/dot_config/desktop-customization/yasb-catppuccin/README.md).

## Ручной порядок библиотеки (опционально)

[Launchpad order](launchpad-order/README.md) сохраняет общий ручной порядок папок
и отдельных приложений и порядок внутри папок. Расширение рассчитано только
на проверенную сборку YASB 2.0.7, имеет проверку SHA256 и откат. Оно не включается
автоматически при восстановлении; обновление YASB требует повторной проверки.
Порядок экспортируется штатным Launchpad-Layout, приватный apps.json в Git не попадает.
