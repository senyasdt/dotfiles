# Как подключить Technical AltGr на новом компьютере

Это две привычные раскладки с техническими символами через правый Alt:
**English - Technical AltGr** и **Russian - Technical AltGr**.
Все готовые файлы лежат рядом с этим README. MSKLC устанавливать не нужно.

Инструкция для **новой Windows 11 x64**. Если обе раскладки уже работают,
повторять установку не нужно. Общее восстановление dotfiles само их не устанавливает.

## 1. Скопировать файлы

Открой папку `provision/windows/keyboard-layouts` в скачанном репозитории.
Скопируй **оба файла** из каждой папки по таблице; Windows попросит права администратора.

| Откуда взять ENTECH.dll и RUTECH.dll | Куда скопировать |
| --- | --- |
| [x64](x64/) | `%WINDIR%\System32` — обычно `C:\Windows\System32` |
| [wow64](wow64/) | `%WINDIR%\SysWOW64` — обычно `C:\Windows\SysWOW64` |

Пути с `%WINDIR%` можно вставить в адресную строку Проводника.
Папки назначения похожи: в **System32 идут x64-файлы**, в **SysWOW64 — wow64-файлы**.
Если на новом компьютере уже есть файлы с этими именами, сначала сохрани их копии;
не заменяй неизвестную личную версию этой инструкцией.

## 2. Зарегистрировать раскладки

Дважды щёлкни по [register-layouts.reg](register-layouts.reg) в Проводнике
и подтверди добавление в реестр. Файл регистрирует только две раскладки
`a0010409` / `a0020419`; языки пользователя выбираются на следующем шаге.

## 3. Выбрать раскладки в Windows

1. Нажми **Win+I → Время и язык → Язык и регион**.
2. Если английского или русского нет в списке, добавь нужный язык. Язык интерфейса Windows менять не требуется.
3. У **English (United States)** нажми **… → Языковые параметры → Клавиатуры → Добавить клавиатуру** и выбери **English - Technical AltGr**.
4. У **Русского** повтори то же самое и выбери **Russian - Technical AltGr**.
5. Убедись, что обе Technical AltGr добавлены, затем убери ненужные обычные **США / US** и **Русская** из этих же списков клавиатур. Сами языки оставь.
6. Выйди из учётной записи Windows и войди снова.

Если названия ещё не появились после регистрации, сначала выйди и войди в Windows,
затем повтори выбор. Переключись **Win+Space** и проверь набор текста на обоих языках.
Путь по настройкам описан также в [инструкции Microsoft](https://support.microsoft.com/en-us/windows/hardware/input-devices/manage-the-language-and-keyboard-input-layout-settings-in-windows).

## Помощник после Apex

После восстановления dotfiles помощник стартует при входе автоматически,
когда установлены обе эти раскладки. Он убирает стандартные дубли после выхода
из Apex. Дополнительно включать его или запускать AHK для этого не нужно.
Если дубли остаются, диагностика находится в
`desktop-customization/keyboard-layout-guard/status.txt` и `events.log`.

## Что сохранено в репозитории

- [source](source/) — исходники KLC владельца, `Public domain`, `Personal`.
- [x64](x64/) — те же DLL, которые использовались на HOMEPC 29 октября 2026.
- [wow64](wow64/) — версии для 32-битных приложений, собранные MSKLC 1.4 / KbdUTool 3.40 из этих KLC с `-a -o`.
- [manifest.json](manifest.json) — SHA256 исходников и DLL для проверки сохранённых файлов.

Самописный установщик, автоматическое изменение языкового профиля и отдельный
механизм отката удалены. Ручная установка на чистую Windows ещё не проверена
на отдельной машине; готовые файлы, архитектуры и контрольные суммы проверены.
