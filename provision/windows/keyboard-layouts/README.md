# Technical AltGr: переносимый комплект

Личные раскладки владельца: English — `a0010409`, Layout Id `a001`, `ENTECH.dll`;
Russian — `a0020419`, Layout Id `a002`, `RUTECH.dll`. Установщик поддерживает
**x64 Windows 10/11**. ARM64 и 32-битная Windows не поддерживаются этим комплектом.

Обычный `restore.ps1 -Profiles full,desktop -Apply` устанавливает комплект
автоматически. Отдельный MSKLC на новом ПК не нужен. Windows запросит UAC для
недостающих системных файлов/регистрации; профиль языков настраивается в исходном
пользовательском процессе, даже если для UAC использована другая учётная запись.
После первой установки нужно выйти из Windows и войти снова. Автоматического
выхода, перезагрузки, закрытия приложений и смены языка интерфейса нет.

Для отдельного просмотра плана/установки использовать **Windows PowerShell 5.1 x64**:

```powershell
& "$src\provision\windows\Install-TechnicalLayouts.ps1" -Action Plan
& "$src\provision\windows\Install-TechnicalLayouts.ps1" -Action Apply
# Только если раскладки на конкретном компьютере не нужны:
& "$src\provision\windows\restore.ps1" -Profiles full,desktop -Apply -SkipTechnicalLayouts
```

На HOMEPC передать `-Root "$env:USERPROFILE\WorkingFolder\desktop-customization"`.
Повторный запуск оставляет совпадающие DLL и регистрацию нетронутыми. При
конфликте имён DLL/идентификаторов/контрольных сумм установка останавливается.
Единственная автоматическая замена существующего файла — обнаруженная на HOMEPC
копия **нашей же x64 DLL в SysWOW64**, которая заменяется проверенной WOW64-версией.
Старые файлы предварительно сохраняются с контрольными суммами.

Языковой API Windows сохраняет порядок и настройки существующих языков,
добавляет недостающие en-US/ru-RU, заменяет только обычные US/Russian input tips
соответствующими Technical AltGr. Другие раскладки сохраняются. Русский тег `ru`
повторно используется. Защитный помощник проверяет наличие обеих кастомных
раскладок и после выхода из Apex удаляет временно добавленные стандартные дубли.

Резервные копии машинного состояния и пользовательского профиля раздельные:
`desktop-customization/backup/technical-layouts-{machine,user}-*/snapshot.json`.
Установщик печатает точные пути. Для отката передать конкретный каталог:

```powershell
& "$src\provision\windows\Install-TechnicalLayouts.ps1" -Action Rollback -BackupDirectory $backup
```

Сначала откатывать пользовательский профиль, затем машинную установку.
Между этапами выйти и войти в Windows, чтобы освободить загруженные DLL.
Изменённые после установки языки/файлы/регистрация блокируют откат, чтобы не
затирать последующие правки. Пустые созданные ключи HKLM могут остаться после
удаления их значений; содержимое других раскладок не затрагивается.

## Происхождение и сборка

Срез 29 октября 2026. KLC взяты из `Documents/kb-layouts/technical-altgr` владельца;
в обоих исходниках указано `COPYRIGHT "Public domain"`, `COMPANY "Personal"`.
x64 DLL сохранены из той же папки и побайтно совпадают с действующими System32.
Они созданы MSKLC 1.4 / KbdUTool 3.40. WOW64 DLL заново собраны из этих же KLC
установленным Microsoft Keyboard Layout Creator 1.4, `bin/i386/kbdutool.exe`:

```powershell
# В двух отдельных пустых рабочих каталогах с копиями обоих KLC:
# x64:
& $kbdutool -n -a -m en-technical-altgr.klc
& $kbdutool -n -a -m ru-technical-altgr.klc
# WOW64:
& $kbdutool -n -a -o en-technical-altgr.klc
& $kbdutool -n -a -o ru-technical-altgr.klc
```

Бинарники не подписаны, как и исходная личная установка. `manifest.json`
фиксирует SHA256 каждого исходника и DLL, архитектуру PE и точные идентификаторы.
Перед установкой проверяются все файлы. KLC и DLL сохраняются Git без перевода
строк. Новая сборка требует повторной проверки и обновления manifest; никакой
компилятор/скачивание DLL при обычном восстановлении не используется.

## Проверено

Проверены контрольные суммы/архитектуры, слияние языков, повторное планирование,
отказ при повреждении DLL, защита неизвестных файлов и проверки отката на
изолированном реестре. На HOMEPC план видит правильные x64 DLL и регистрацию,
два известных WOW64-исправления, отсутствие изменений языкового профиля.
Полная установка на чистую Windows/новый профиль и реальный UAC/откат системных
DLL требуют проверки на отдельной машине; эти сценарии здесь не имитируются
как успешно выполненные.

Используются [Set-WinUserLanguageList](https://learn.microsoft.com/en-us/powershell/module/international/set-winuserlanguagelist?view=windowsserver2025-ps)
и стандартная [регистрация раскладок Windows](https://learn.microsoft.com/en-us/windows/win32/intl/using-registry-string-redirection).
