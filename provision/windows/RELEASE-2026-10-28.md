# Windows desktop: выпуск 28 октября 2026

## Ветки

| Ветка | Назначение |
| --- | --- |
| master | LeopardWM 0.3.4 + YASB Cold Grey, основной вариант |
| komorebi | Общий актуальный YASB/AHK-профиль, komorebi/whkd по умолчанию |
| komorebi-scrolling | История и рецепт экспериментальной native-ленты komorebi |

Основной default задаётся одним JSON в `.chezmoidata`. Явный локальный выбор
имеет приоритет; смена ветки сама не переключает менеджер. Перенос багфиксов
между master/komorebi — merge общей базы с сохранением единственного значения
windowManager ветки. Не дублировать source helpers вручную.

## Изменения

- Объединены upstream master (Linux/macOS, mise/Java/Docker), стабильная Windows
  интеграция, исправления библиотеки и подтверждённый профиль LeopardWM.
- Native portable LeopardWM закреплён хэшем. Restore теперь устанавливает его
  и активирует без предварительного запуска komorebi; повторный installer проверяет
  файлы. Обновление TOML имеет резервную копию и rollback при ошибке reload.
- Общий автозапуск запускает выбранный WM; старые пути совместимы. Новых фоновых
  наблюдателей и второго WM не добавлено. Komorebi доступен как запасной Scoop-пакет.
- Лента с независимой шириной, Alt+колесо, девять пространств, текущая плавность.
  Начальные размеры согласованы: редакторы/CAD 100%, Telegram 50%, default 61.8%.
  Unity/Hub → 8; Fusion/Orca/Prusa → 9. Уже открытые окна не перетаскиваются правилами.
- YASB: холодный серый полупрозрачный стиль, компактный трей, dock hit targets,
  активная подложка, исправленное скрытие, библиотека/папки/поиск и пустая сетка.
- Шрифт значков входит в установку. Сохранены управляемый Cold Grey для Code,
  Terminal/WezTerm и быстрый возврат к Nord Cold Grey в меню WezTerm.
- Меню очищены от старых тестов и MyDockFinder. Одна группа текущего WM;
  безопасное восстановление отрисовки ChatGPT остаётся доступным.
- AHK ON/OFF — атомарный общий переключатель; детали в ↻ → AHK. Игровые
  blocker rules, ручное выключение и 15-секундное возобновление сохранены.
- Документация описывает новую машину, смену вариантов, приватные зависимости,
  реальные границы проверки и прежнюю историю вместо противоречащих инструкций.

## Проверка

Локально: PS5.1 и PS7, 9 сочетаний OS/profile, три YAML по схеме YASB 2.0.7,
48 AHK assertions, 23 appearance checks, selection/first-login/dispatch,
idempotent panel conversion, isolated helper builds. Из закреплённого архива
проверены установка LeopardWM, повторная проверка и отказ при изменении controller.
Реальные AHK и второй WM в проверках не запускались. CI запускает эти проверки
на Windows и рендеры на Ubuntu/macOS в трёх профилях.

Пакетная установка с нуля в чистой Windows VM, reboot, новая учётная запись,
игры и физические HID не проверены. Только один монитор в switch wrapper.
Всё необходимое для восстановления конфигурации хранится в source; приватные
ключи, DPAPI, выбранные устройства, прошивки и лицензии остаются внешними условиями.
